# tdm-dash: notes for Claude

Digital instrument cluster for a 1992 Yamaha TDM 850 (3VD): Raspberry Pi Zero 2 W (Buildroot Linux + Rust/Slint UI) and an RP2040 co-processor (Rust/embassy) over USB CDC. The approved plan, milestones M0–M6, is summarised in `README.md` and `docs/adr/`.

## Language

- Documentation (`docs/`, `README.md`): **Italian**.
- Code, comments, commit messages: **English**.

## Diagrams

- Everything that is not a real schematic is **Mermaid inside Markdown**. No ASCII art diagrams.
- Real schematics: KiCad 9 in `hardware/kicad/`.
- Wiring harnesses: WireViz YAML in `hardware/harness/`.
- Exports go to `hardware/exports/`.

## Facts about the bike

- Every fact about the original wiring is tagged [VERIFICATO] / [DA VERIFICARE] / [IPOTESI] in `docs/ricerca/impianto-originale.md`.
- Never present a [DA VERIFICARE] wire colour as certain in schematics or harnesses.

## Commands

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo build -p tdm-proto -p tdm-core --target thumbv6m-none-eabi   # no_std check
cargo clippy -p tdm-dash --no-default-features --features kms --all-targets -- -D warnings
cargo run --release -p tdm-dash --no-default-features -- --screenshot design/screenshots   # refresh reference screens
cargo build --release --target aarch64-unknown-linux-gnu -p tdm-dash --no-default-features --features kms  # needs gcc-aarch64-linux-gnu
python3 tools/check_mermaid.py --mmdc <path-to-mmdc> [--chrome <chromium>]
docker run --rm -u 0 -v "$PWD":/w -w /w kicad/kicad:9.0.9 sh -c 'python3 hardware/kicad/generate.py && hardware/kicad/export.sh'   # schematic: regenerate, ERC, pin check, export
make -C os release            # Buildroot SD image (needs the os/buildroot submodule, ~1 h; CI: os-image.yml)
```

In the cloud container, Chromium is at `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`. Install mermaid-cli with:

```sh
PUPPETEER_SKIP_DOWNLOAD=1 npm i --prefix "$SCRATCH/mmdc" @mermaid-js/mermaid-cli@11.16.0   # outside the repo
```

## Crates

- `tdm-proto` (no_std): messages and COBS/CRC framing.
- `tdm-core` (no_std): `PulseMeter`, `Debouncer`, FRAM records, `McuCore` (the MCU application logic, shared by firmware and simulator).
- `tdm-logic`: profile, conversions, filters, warnings, `Dash` state machine → `ViewModel`.
- `tdm-link`: `SimMcu` vehicle simulator, serial/replay sources, `tdmctl`.
- `tdm-dash`: Slint UI (`ui/dash.slint`), platforms `desktop`, `kms`, headless screenshots/bench.
- All font sizes used in `ui/dash.slint` must be listed in `crates/tdm-dash/build.rs` (`FONT_SIZES`), and any non-ASCII character that only appears in Rust strings must be added to the hidden `Text` in `dash.slint`, or the software renderer cannot draw it.

## Hardware and OS

- The KiCad schematic is generated by `hardware/kicad/generate.py`: edit that, never the `.kicad_sch` files. Commit the regenerated files and SVG exports; CI diffs them.
- `tools/check_pinmap.py` ties the schematic to `firmware/src/main.rs` and to the profile constants: change pins in both places.
- The Buildroot package builds `tdm-dash` from this checkout (`os/br2-external/package/tdm-dash`, ADR 0011).

## Invariants

- `tdm-proto` and `tdm-core` are `no_std` and shared by the firmware and the simulator.
- Protocol variants and fields are append-only; breaking changes bump `PROTO_VERSION`.
- The MCU is the source of truth for the odometer (FRAM). The Pi only displays it.
- The displayed speed must never be below the true speed (UNECE R39); keep the legal-bounds test green.
- No Yamaha logos or trademarks in assets.
