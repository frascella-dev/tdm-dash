# A · Appendici

## A.1 Codice colori dei fili Yamaha

| Sigla | Colore | Sigla | Colore |
|---|---|---|---|
| B | Nero | L | Blu |
| Br | Marrone | O | Arancione |
| Ch | Cioccolato | P | Rosa |
| Dg | Verde scuro | R | Rosso |
| G | Verde | Sb | Azzurro (sky blue) |
| Gy | Grigio | W | Bianco |
| Lg | Verde chiaro | Y | Giallo |

Due sigle separate da `/` indicano colore del filo e colore della riga: `L/W` è blu con riga bianca.

## A.2 Glossario

| Termine | Significato |
|---|---|
| ADC | Convertitore analogico-digitale: trasforma una tensione in un numero |
| Attivo alto / basso | Un ingresso "attivo alto" è acceso quando riceve +12 V; "attivo basso" quando è collegato a massa |
| Blanking | Tempo dopo un impulso in cui il firmware ignora altri impulsi (oscillazioni della bobina) |
| Buildroot | Strumento che compila da zero un sistema Linux minimale |
| COBS | Codifica che permette di separare i pacchetti con un byte 0x00 |
| CRC | Codice di controllo che scopre i pacchetti corrotti |
| DPI | Interfaccia video parallela del Raspberry Pi verso display RGB |
| DRM/KMS | Interfaccia del kernel Linux per disegnare direttamente sul display |
| EROFS | File system compresso in sola lettura |
| FRAM | Memoria non volatile scrivibile praticamente all'infinito, veloce come la RAM |
| MCU | Microcontrollore (qui il Raspberry Pi Pico) |
| NTC | Resistenza che diminuisce quando la temperatura sale |
| Optoaccoppiatore | Componente che trasmette un segnale con la luce, isolando elettricamente i due lati |
| PWM | Segnale acceso/spento molto veloce, usato per regolare la luminosità |
| TCI | Centralina d'accensione a scarica induttiva della TDM |
| TVS | Diodo che assorbe le sovratensioni brevi |
